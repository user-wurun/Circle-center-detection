# 摄像头圆心检测

使用摄像头实时识别画面中的细黑色曲线，并根据曲线端点的垂直平分线估计圆心。程序会在摄像头画面中标出候选交点、候选圆心，以及画面中心到平均圆心的连线。

## 功能

- 使用高反差保留增强灰度图像中的局部细节。
- 使用黑帽变换突出黑色细线，并通过闭运算和轮廓筛选减少噪声。
- 对每条检测到的曲线提取两个端点。
- 计算各端点连线的垂直平分线，并求两两交点。
- 将画面内的交点取平均，作为最终的平均圆心。
- 在窗口中实时显示候选交点、平均圆心和检测数量。

## 环境要求

- Windows
- Python 3.10 或更高版本（代码使用了内置泛型和 `|` 联合类型语法）
- 可用的摄像头
- Windows 字体文件 `C:\Windows\Fonts\NotoSansSC-VF.ttf`

安装依赖：

```powershell
python -m pip install opencv-python numpy pillow
```

如果系统中没有上述字体，请修改 `main.py` 顶部的 `FONT_PATH`，指向一个可用的中文字体文件，否则程序无法绘制中文标注。

## 运行

在项目目录中执行：

```powershell
python main.py
```

程序默认打开 `0` 号摄像头，并在名为 `Camera Circle Search` 的窗口中显示结果。按 `q` 或 `Esc` 退出。

## 参数调整

当前参数在 `main()` 中直接设置，不支持命令行参数：

| 参数 | 默认值 | 作用 |
| --- | ---: | --- |
| `camera_index` | `0` | 摄像头编号 |
| `radius` | `3.0` | 高斯模糊半径 |
| `strength` | `1.0` | 高反差增强强度 |
| `contrast` | `1.0` | 增强结果对比度 |
| `black_threshold` | `18` | 黑帽响应二值化阈值 |
| `min_curve_length` | `30.0` | 轮廓最小周长 |
| `blackhat_size` | `15` | 黑帽椭圆核大小，必须是不小于 3 的奇数 |
| `min_curve_span` | `50.0` | 曲线端点之间的最小跨度 |

误检较多时，可提高 `black_threshold`、`min_curve_length` 或 `min_curve_span`；细线漏检时，可适当降低 `black_threshold`。调整后重新运行程序即可生效。

## 注意事项

- 计算出的平均圆心是所有有效垂直平分线交点的算术平均值，并不等同于完整圆拟合结果。
- 线段接近平行或交点落在画面外时，不会被计入候选圆心。
- 摄像头权限、光照、背景纹理和黑线宽度都会影响检测效果。
